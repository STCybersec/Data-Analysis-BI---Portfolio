# 📦 Dataset - Transactions

## About This Dataset

`Transactions` contains **500,000 shipment records** generated using Python and loaded into SQL Server, covering a wide range operations in South Africa, UK, USA and UAE from 2021 to 2025.

---

## Why Only a Sample Is Stored Here

The full `Transactions` CSV exceeds GitHub's 25MB file size limit.

The complete 500,000 row dataset can be recreated by running:
```
Project6_Fintech.sql
```
against a local SQL Server instance with the database `Project6_Fintech` created.
